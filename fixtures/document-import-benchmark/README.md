# 文档导入固定评测集

本目录只保存项目原创、完全虚构的测试资料及人工标准答案，不包含真实工作区、凭据或第三方数据集原文。

`cases.json` 中每个用例包含：

- `text`：交给文档导入器的原文；
- `expectedNodes`：应当出现的节点名称、必须保留的事实和允许引用；
- `forbiddenNodeNames`：不应被模型当作节点创建的标题、指令或秘密；
- `tags`：用例覆盖的风险和文本形态。

标准答案采用规范化后精确名称匹配。它有意保持保守：可选的细分方式不列入标准答案，避免把一种人为建模风格强加给模型。引用方向与应用一致，为“当前节点引用目标节点”。

运行方式见 `DEVELOPMENT.md`。公开数据集不能放进本目录；转换后的公开数据和模型预测统一写入已忽略的 `artifacts/`。

公开补充数据的官方来源：

- CLUENER2020：<https://github.com/CLUEbenchmark/CLUENER2020>
- DocRED：<https://github.com/thunlp/DocRED>

下载与使用第三方数据前应自行核对其当前许可和来源条款；本项目不自动下载或再分发这些原文。
