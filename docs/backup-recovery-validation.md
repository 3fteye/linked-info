# 备份恢复自动化验收

## 2026-10-13 切片

已有测试分别覆盖加密恢复、错误密码、保留候选选择、版本删除和最终可见对象复核。补齐缺失的组合验证：合成工作区保存与编辑、实际 S3 适配器传输密文、下载校验、无原设备 vault 的新目录恢复，以及故障后原工作区和旧快照不变。

夹具仅在 `cfg(test)` 中编译，监听 `127.0.0.1:0`、关闭代理和重定向、使用固定虚构凭据。它保存对象状态并提供本测试需要的 ListObjectsV2、GET、PUT、ListObjectVersions 和带版本 DELETE；可以在 PUT 提交前断开连接、篡改一次下载。请求有容量和超时限制，退出回收线程。生产构造器仍只接受 HTTPS。

保留验证复用生产候选函数和证明存在检查，在同一夹具执行可验证删除，断言最新快照和演练证明快照保留。错误密码不安装工作区；下载损坏被完整性校验拒绝；上传中断不产生成功快照。

测试仅由现有 GitHub Actions Windows 桌面库测试执行，不连接真实服务商，不读取用户配置、凭据库或工作区。覆盖不包括 SigV4 服务端密码学校验、TLS、真实服务商版本策略、UI 输入、进程强杀或电源故障；这些不能根据此夹具宣称通过。首次结果以 PR 的固定 SHA/CI 记录为准，本文不预先声明测试成功。
