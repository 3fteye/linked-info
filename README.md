# 关联信息（Linked Info）

关联信息是一款本地优先的桌面信息管理应用。它不预先规定“账号”“服务”“脚本”或“标签”等固定类型，而是让所有信息使用同一种节点表示，再通过节点之间的引用建立上下文。

当前项目处于早期可用阶段，适合试用和参与开发，不建议把它当作唯一备份。

## 核心概念

每个节点只有两个信息字段：

- 名称：可以为空；非空名称在忽略首尾空白和大小写后必须唯一。
- 内容：可以为空，当前使用纯文本。

节点之间可以建立有方向的引用。被引用的节点可以自然地承担标签作用，也可以代表人物、服务、项目、来源或其他信息。

如果一段信息只属于两个节点之间的关系，可以新建第三个普通节点，同时引用双方。例如“账号 A 的 OpenAI 订阅”节点同时引用“账号 A”和“OpenAI”，订阅状态写在这个关系节点中。底层不需要增加账号或服务专用类型。

## 当前功能

- ComfyUI 风格的无限画布，可平移、缩放和自由摆放节点。
- 在节点内直接编辑名称和纯文本内容。
- 从节点端口拖动建立引用；拖到空白处可以搜索并连续引用现有节点，也可以直接创建缺失节点。
- 节点内部显示它直接引用的目标。
- 按名称搜索、仅显示未命名节点，以及按多个引用目标进行 AND 筛选。
- 节点创建、编辑、移动、删除和引用增删的撤销与重做。
- 删除前确认，并同步清理相邻引用和画布布局。
- 完整工作区导出、严格校验后导入，以及导入前本地恢复副本。
- Rust 管理的本地原子保存、关闭前刷新和桌面单实例。
- 对单个节点明确触发智能引用：可使用本地文本向量模型或可配置的远端嵌入接口，查看带相似度分数的候选并手动建立引用。
- 把 TXT、Markdown 或粘贴的杂乱文本交给本地 LLM 分段整理为导入草稿；逐项选择、修正并查看画布差异后，再作为一个事务加入现有工作区。
- 可选的阈值自动引用；默认关闭，只在用户明确执行一次分析时增量添加达到阈值的普通引用。
- 简体中文和英文界面。

## 本地 LLM 复核

设置中的“本地 LLM 复核”是智能引用的可选第二层。应用先用向量和已有引用关系产生有限候选，再由本地 Qwen3 1.7B Q8 模型把候选分为“建议引用”“不确定”和“无匹配”。模型只能选择已有候选，不能新建或修改节点；所有结果均需手动确认。

首次使用需要下载约 1.71 GiB 的固定版本模型，下载支持进度、速度、预计时间、取消和续传。模型文件保存在系统应用缓存目录，不进入工作区、导出、远端同步或 Git。推理通过安装包内固定版本的 llama.cpp 在本机 CPU 上运行，只监听本机回环地址；关闭开关或退出应用时会终止模型进程。

开启 LLM 复核后，原来的推荐分阈值自动引用会暂停，避免模型判断在未经确认时写入正式引用。关闭 LLM 后，第一层智能引用行为保持不变。

## 获取应用

项目目前还没有正式 Release 和签名安装包。开发阶段只验证和生成实际使用的 Windows 版本；可以在仓库的 **Actions → Desktop packages** 中打开最近一次成功运行，下载构建产物：

- `linked-info-windows`：Windows 便携包。必须完整解压，并保持 `linked-info-desktop.exe` 与旁边的 `llama-runtime` 目录相对位置不变；不能只移动 EXE。

Windows 便携版尚未进行商业代码签名，系统可能显示 SmartScreen 提示。只应从本仓库对应提交的 Actions 产物获取程序。

## 基本使用

1. 点击画布工具栏的 `+`，或在画布空白处右键并选择新建节点。
2. 直接在节点内填写名称和内容。未命名节点也会保存，可以通过“仅未命名”集中整理。
3. 从节点的引用输出端拖动到另一个节点即可建立引用。
4. 将引用拖到空白处会打开搜索：
   - 对已有候选按 `Space`：引用并继续搜索。
   - 对已有候选按 `Enter`：引用并关闭搜索。
   - 没有候选时按 `Enter`：创建新节点、建立引用并关闭搜索。
   - 按 `Escape`：取消。
5. 在顶部选择多个引用筛选条件时，只显示同时引用全部条件节点的信息。
6. 在设置中选择本地或远端智能引用方式。右键某个节点并选择“智能引用”，即可查看候选；本地模型首次使用时会下载到当前设备。相似度是排序分数，不是正确率，开启自动引用前应先用自己的数据校准阈值。

### 导入杂乱文档

点击顶部的“导入文档”，选择 UTF-8 编码的 `.txt`、`.md`、`.markdown` 文件，或直接粘贴原始文本。第一版最多读取 1 MiB 文件、120,000 个字符和 64 个模型分段，仅使用设置中选择的本地 LLM，不会把原文发送到远端。

模型结果先进入独立草稿。可以排除候选、修改新增节点的名称与内容，并调整引用名称；名称精确匹配到当前工作区的候选会显示为只读已有节点，确认时不会覆盖其内容。之后进入画布差异预览，只有点击“确认导入”才会一次性保存，并且可以用撤销回退整个导入。

每次确认导入都会额外建立一个“来源：文件名”节点，保存原文件名、导入时间、SHA-256、本地模型标识和完整原文；所有选中结果都会引用它。这样模型拆分后的节点仍能追溯到未经改写的原始资料。模型可能漏项或误分，因此草稿检查和画布确认不能省略。

画布未处于文字输入状态时支持：

- `Ctrl+A`：选择当前可见节点。
- `Delete` / `Backspace`：确认后删除所选节点。
- `Ctrl+Z`：撤销。
- `Ctrl+Y` / `Ctrl+Shift+Z`：重做。

文字输入框获得焦点时仍使用系统原生的文字编辑快捷键。

## 数据与隐私

正式桌面端把工作区保存在系统应用数据目录下，应用标识为 `com.linkedinfo.desktop`。Windows 上已经验证的路径是：

```text
%APPDATA%\com.linkedinfo.desktop\workspace.v1.json
```

导入前恢复副本保存在同一目录的 `workspace.recovery.v1.json`。浏览器开发模式使用 `localStorage`，正式桌面端首次升级时会把通过校验的旧数据迁移到 Rust 文件存储。

桌面端支持可选的主密码加密工作区。未启用时，节点、引用和恢复副本仍以明文保存在本机，不适合保存密码、访问令牌或双因素恢复信息；在“设置 → 工作区加密”设置主密码后，正式工作区、恢复副本、正常导出和不可读数据导出都会使用认证加密。忘记主密码将无法恢复数据，当前版本尚未提供恢复密钥，请把主密码保存在应用之外的安全位置。

启用加密时会原子迁移现有工作区并清除向量磁盘缓存。加密工作区只在当前解锁会话使用 64 MiB 内存向量缓存，不把派生向量写回 SQLite。应用启动时必须先解锁；设置页可以修改主密码、轮换数据密钥、立即锁定，或为当前设备启用“系统快速解锁”。Windows 快速解锁每次都会要求 Windows Hello PIN、指纹或人脸确认，通过后才读取 Credential Manager 中的独立随机设备密钥；它不保存主密码，也不进入导出、备份或同步。取消或验证失败时工作区保持锁定，仍可输入主密码。macOS 与 Linux 的逐次用户验证适配器尚未完成，因此当前不开放快速解锁入口。

“修改主密码”只重新保护原数据密钥，不会逐个重写节点，也不会关闭已经登记的系统快速解锁。“轮换数据密钥”用于怀疑旧数据密钥或解锁会话泄露的情况：它会立即锁定应用，用新的随机密钥重加密当前工作区、恢复副本和本机自动历史，并替换当前设备的快速解锁凭据。过程可在异常中断后恢复；完成后需要使用轮换时填写的主密码或系统快速解锁重新进入。已经另存到其他目录的导出文件是独立副本，不会随之改变。

桌面端会在成功保存有效变更后维护当前设备的自动备份历史：第一份立即建立，之后内容变化时最多每小时一份，默认最多 30 份、总计不超过 512 MiB，并且最长保留 90 天。设置页可以查看时间、大小、保留期限和损坏状态；选择恢复后会进入只读画布预览，在同一坐标系中查看恢复前、叠加差异和恢复后三种布局，节点与引用的新增、删除、内容变化和位置变化会直接标在画布上。确认前当前工作区不会改变，完全一致时不会执行无意义替换；恢复前仍会把当前工作区保留为单独的恢复副本。加密工作区的历史文件同样是认证密文，启用加密时既有明文历史会一起迁移。自动历史位于本机应用数据目录，不能应对磁盘损坏、系统重装或设备丢失，因此仍应定期把加密导出保存到其他设备。

在 Windows 加密工作区中，可以右键有内容的节点并选择“复制内容（按秘密处理）”。应用复制完整节点内容；如果之后没有复制其他内容，会在 45 秒后自动清空，手动锁定、闲置锁定、Windows 会话锁定或休眠、轮换数据密钥以及正常退出时都会提前清空。普通选中复制不受影响，也不会自动清除。Windows 剪贴板历史、跨设备同步以及应用或系统崩溃仍可能留下副本，因此秘密复制不能替代关闭这些系统功能。

桌面应用默认仍然只使用本地文件，但加密工作区可以在设置页登记一个或多个可选异机备份目标。可选连接包括独立 Cloudflare Worker + R2，以及一个通用 S3 兼容目标；后者提供 Backblaze B2、Tigris、Oracle OCI 和自定义 S3 配置模板，而不是为每家服务复制一套实现。服务商不能取得主密码、数据密钥、节点内容、引用或布局，仍会看到对象键、文件大小、创建时间、版本数量和访问频率。Worker 应用令牌或 S3 访问密钥只保存于当前系统安全存储，不进入工作区或导出；端点、凭据引用和自动保留设置组成的本机目标配置由系统安全存储中的独立设备密钥进行 HMAC 认证，离线篡改会在读取凭据或发起网络请求前失败。旧版未认证配置只允许在设备尚未建立认证密钥时迁移一次，不能用旧格式绕过后续校验。可以手动上传、完整下载并在本机重算 SHA-256、进入恢复前画布差异预览，或执行不替换当前数据的“恢复演练”：输入快照创建时的主密码后，Rust 会在独立临时目录建立并重新解锁一个全新工作区，核对节点、引用和布局，成功清理后记录演练时间。每个目标还可以独立启用默认关闭的自动异机备份，并选择 24、72 或 168 小时的最短上传间隔；只有实际数据变更并成功保存到本地后才会进入待上传状态，多个变更会合并，纯平移、缩放、搜索和筛选不会上传。远端失败不会阻止或回滚本地保存，目标会保留待上传状态；自动上传成功也不替代完整校验或恢复演练。没有本地加密工作区时也可临时输入同一套连接信息执行新设备恢复；临时凭据不会自动保存。Cloudflare 只是一个可替换目标，桌面端不依赖它启动；现有 Worker + D1 节点 API 仍与秘密备份路径完全分离。

远端快照和目标具有分开的删除语义：“从本机移除目标”只清除本机配置与系统安全存储中的连接凭据，服务商上的密文仍然保留；单个快照删除以及“删除全部远端快照并移除目标”会真正向该目标发送删除请求，均要求重新认证和再次确认。批量删除中途失败时应用会保留目标连接以便重试。每个目标还可选择默认关闭的自动保留策略；启用时，成功上传新快照后才按最大数量和保留天数清理旧快照，并始终保留最新快照和最近一次通过恢复演练的快照。服务商的对象版本或软删除规则可能继续保留已删除对象，应用不会把普通对象删除描述成介质级安全擦除。

智能引用默认使用本地模型。只有用户主动选择远端方式并执行分析时才会发送文本；由于候选必须先经过全库向量比较，缓存未命中时，当前工作区全部非空节点的有界分段文本都可能发送到用户填写的嵌入接口，而不只是最终候选。设置页和分析进度会显示本次最多涉及的节点数与分段数。远端令牌只保存在当前应用内存会话中，关闭应用后清除，不进入工作区、设置文件或导出备份。远端 AI 与远端密文同步不是一回事：AI 服务必须看到明文才能理解内容，所以未来密码保护模式默认不会把解锁后的工作区交给远端 AI。

## 当前限制

- 没有富文本和附件。后续扩展方向是保持节点内容为可移植字符串，通过独立内容处理器增加安全 Markdown 预览、TOTP 实时验证码和受权限控制的脚本预览/执行，而不是增加固定节点类型。
- 智能引用没有重排模型、后台批处理或按一次分析自动撤销；本地 LLM 只复核当前一次分析的有限候选。
- 没有多设备双向同步、冲突合并或终端用户账号系统；当前远端能力只做追加式客户端密文快照和显式恢复。
- 加密工作区尚无恢复密钥和独立的秘密字段；密码等秘密目前仍作为节点字符串整体加密。系统快速解锁是当前设备上的便利入口，不是第二因素，也不能替代主密码或备份。
- 加密工作区默认闲置 15 分钟后锁定，也可选择 5/30 分钟或关闭；Windows 会话锁定、用户切换、远程断开和休眠会立即撤销 Rust 明文授权。锁定前启动的本地嵌入与 LLM 结果会因代次失效而被丢弃。修改主密码、完整/原始导出和关闭系统快速解锁要求当前主密码或新的 Windows Hello 验证。
- 正式 WebView 已启用仅允许打包资源与必要 IPC 的 CSP；主窗口 capability 只保留事件监听，文件导入导出和秘密剪贴板都由限定用途的 Rust 命令执行。设置页可在重新认证后清除全部自动历史与恢复副本而保留当前工作区，也可以在再次验证身份并输入确认短语后销毁当前工作区、加密元数据、本机历史、恢复副本和设备快速解锁入口。销毁不会寻找或删除用户已经保存到其他目录的导出文件；文件系统也不保证 SSD 单文件安全擦除，存储介质残留仍依赖 BitLocker 等全盘加密。仍不应加载不可信 HTML、插件或脚本。
- 公开构建尚未提供代码签名和稳定更新通道。
