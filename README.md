# 关联信息（Linked Info）

关联信息是一款本地优先的桌面信息管理应用。它不预先规定“账号”“服务”“脚本”或“标签”等固定类型，而是让所有信息使用同一种节点表示，再通过节点之间的引用建立上下文。

当前项目处于早期可用阶段，适合试用和参与开发，不建议把它当作唯一备份。

## 核心概念

每个节点只有两个信息字段：

- 名称：可以为空；非空名称在忽略首尾空白和大小写后必须唯一。
- 内容：可以为空，当前使用纯文本。

节点之间可以建立有方向的引用。被引用的节点可以自然地承担标签作用，也可以代表人物、服务、项目、来源或其他信息。

如果一段信息只属于两个节点之间的关系，可以新建第三个普通节点，同时引用双方。例如“账号 A 的 OpenAI 订阅”节点同时引用“账号 A”和“OpenAI”，订阅状态写在这个关系节点中。底层不需要增加账号或服务专用类型。

## 当前功能

- ComfyUI 风格的无限画布，可平移、缩放和自由摆放节点。
- 在节点内直接编辑名称和纯文本内容。
- 从节点端口拖动建立引用；拖到空白处可以搜索并连续引用现有节点，也可以直接创建缺失节点。
- 节点内部显示它直接引用的目标。
- 按名称搜索、仅显示未命名节点，以及按多个引用目标进行 AND 筛选。
- 节点创建、编辑、移动、删除和引用增删的撤销与重做。
- 删除前确认，并同步清理相邻引用和画布布局。
- 完整工作区导出、严格校验后导入，以及导入前本地恢复副本。
- Rust 管理的本地原子保存、关闭前刷新和桌面单实例。
- 对单个节点明确触发智能引用：可使用本地文本向量模型或可配置的远端嵌入接口，查看带相似度分数的候选并手动建立引用。
- 可选的阈值自动引用；默认关闭，只在用户明确执行一次分析时增量添加达到阈值的普通引用。
- 简体中文和英文界面。

## 获取应用

项目目前还没有正式 Release 和签名安装包。可以在仓库的 **Actions → Desktop packages** 中打开最近一次成功运行，下载对应平台的构建产物：

- `linked-info-windows`：Windows 便携版可执行文件。
- `linked-info-macos`：macOS 打包产物。
- `linked-info-linux`：Linux 打包产物。

Windows 便携版尚未进行商业代码签名，系统可能显示 SmartScreen 提示。只应从本仓库对应提交的 Actions 产物获取程序。

## 基本使用

1. 点击画布工具栏的 `+`，或在画布空白处右键并选择新建节点。
2. 直接在节点内填写名称和内容。未命名节点也会保存，可以通过“仅未命名”集中整理。
3. 从节点的引用输出端拖动到另一个节点即可建立引用。
4. 将引用拖到空白处会打开搜索：
   - 对已有候选按 `Space`：引用并继续搜索。
   - 对已有候选按 `Enter`：引用并关闭搜索。
   - 没有候选时按 `Enter`：创建新节点、建立引用并关闭搜索。
   - 按 `Escape`：取消。
5. 在顶部选择多个引用筛选条件时，只显示同时引用全部条件节点的信息。
6. 在设置中选择本地或远端智能引用方式。右键某个节点并选择“智能引用”，即可查看候选；本地模型首次使用时会下载到当前设备。相似度是排序分数，不是正确率，开启自动引用前应先用自己的数据校准阈值。

画布未处于文字输入状态时支持：

- `Ctrl+A`：选择当前可见节点。
- `Delete` / `Backspace`：确认后删除所选节点。
- `Ctrl+Z`：撤销。
- `Ctrl+Y` / `Ctrl+Shift+Z`：重做。

文字输入框获得焦点时仍使用系统原生的文字编辑快捷键。

## 数据与隐私

正式桌面端把工作区保存在系统应用数据目录下，应用标识为 `com.linkedinfo.desktop`。Windows 上已经验证的路径是：

```text
%APPDATA%\com.linkedinfo.desktop\workspace.v1.json
```

导入前恢复副本保存在同一目录的 `workspace.recovery.v1.json`。浏览器开发模式使用 `localStorage`，正式桌面端首次升级时会把通过校验的旧数据迁移到 Rust 文件存储。

本地工作区目前**没有加密**。不要在节点中保存密码、访问令牌、双因素恢复码或其他必须加密的凭据。建议定期使用应用内导出功能保存独立备份。

当前桌面应用没有连接 Cloudflare 或其他远端服务，也没有账号系统和远端同步。仓库中的 Cloudflare Worker 与 D1 代码只是一个可选后端适配器，不是桌面端运行的必要条件。

智能引用默认使用本地模型。只有用户主动选择远端方式并执行分析时，当前节点及候选节点的分段文本才会发送到用户填写的嵌入接口。远端令牌只保存在当前应用内存会话中，关闭应用后清除，不进入工作区、设置文件或导出备份。

## 当前限制

- 没有富文本和附件。智能引用目前只有文本向量第一层，没有重排模型、LLM 语义判断、后台批处理或自动撤销。
- 没有远端同步、冲突合并和身份认证。
- 没有本地加密或专用凭据保险库。
- 公开构建尚未提供代码签名和稳定更新通道。
