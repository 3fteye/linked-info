# Rust 扩展示例

这是一个独立 Cargo 工作区，只依赖公开的 `linked-info-extension-sdk`。它不读取桌面端、Tauri、React、宿主运行时或工作区领域实现。

示例贡献一个摘要处理器和一个“正文转为大写”动作：处理器返回声明式展示；动作返回节点级扩展元数据和一个必须由宿主预览、复验并确认后才能提交的修改提案。

仓库 CI 会把本目录和 SDK 复制到 Git 检出目录之外，再完成真实 Wasm 构建、组件化、临时发布者密钥生成、签名打包、严格验证、隔离渲染和动作调用。详细命令见 [`docs/extension-sdk.md`](../../docs/extension-sdk.md)。
